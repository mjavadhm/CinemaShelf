# ADR-XXXX: عنوان تصمیم

وضعیت: پیشنهادی / پذیرفته‌شده / جایگزین‌شده

## زمینه
مسئله و محدودیت‌ها چیست؟

## تصمیم
چه انتخابی و با چه دامنه‌ای انجام شد؟

## گزینه‌های دیگر
چه گزینه‌هایی بررسی و چرا کنار گذاشته شدند؟

## پیامدها
مزیت‌ها، هزینه‌ها و ریسک‌ها چیست؟

## بازبینی
چه تغییری باعث بازنگری این تصمیم خواهد شد؟
