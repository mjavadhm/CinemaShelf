# ADR-0002: فیلم مستقل از فایل و منبع

وضعیت: مبنای نیازمندی‌ها.

## تصمیم
Movie هویت مشترک است؛ نسخه‌های محلی به Movie و Source متصل می‌شوند. دادهٔ شخصی به Movie تعلق دارد. قطع منبع حذف رکورد نیست. تکمیل دانلود با ورود به کتابخانه دو رخداد/وضعیت مستقل‌اند.

## پیامد
چند نسخه کارت تکراری نمی‌سازند؛ هارد آفلاین قابل مرور می‌ماند؛ ورود فایل باید idempotent باشد. تشخیص هویت و اصلاح تطبیق نیازمند قرارداد و UI صریح است.
