# نقشهٔ کدهای موجود

این نقشه بر اساس خواندن ساختار و بخش‌هایی از کد و READMEهاست؛ اجرای موفق یا ممیزی کامل ادعا نمی‌شود.

## CinemaShelf قدیمی — legacy/cinemashelf
| فایل | مسئولیت فعلی و نکتهٔ انتقال |
|---|---|
| main.py | تنظیمات، مسیر داده و هماهنگی عملیات؛ مسئولیت‌ها در طراحی جدید تفکیک شوند |
| mover.py | انتقال فیزیکی فیلم‌ها؛ در مسیر پیش‌فرض جدید اجرا نشود |
| fetcher.py | دریافت اطلاعات از OMDb و ذخیرهٔ JSON؛ کاندید Adapter پس از بررسی |
| categorizer.py | دسته‌بندی و ساخت shortcut؛ ابزار اختیاری با وابستگی‌های OS |
| utils.py | parsing نام فیلم، پاک‌سازی نام و سال؛ با تست و بررسی ابهام قابل استفاده |
| stats.py | آمار روی دادهٔ JSON؛ بازنگری برای مدل جدید |
| cli.py | رابط خط فرمان قدیمی |
| cinemashelf_gui.py | رابط PyQt و threadهای عملیات؛ رابط اصلی نسخهٔ جدید نیست |
| setup.py | بسته‌بندی قدیمی؛ وابستگی‌ها نیازمند بازبینی |

دادهٔ JSON، نام پوشه و فایل لزوماً هویت معتبر فیلم نیستند. از فراخوانی مستقیم mover هنگام آزمایش خودداری شود.

## دانلودر — legacy/zarfilm-downloader
| فایل | مسئولیت فعلی و نکتهٔ انتقال |
|---|---|
| app/main.py | FastAPI و endpointها؛ به Routerهای محدود تقسیم شود |
| app/database.py | SQLite، تنظیمات، فیلم‌ها، لاگ و دادهٔ LLM؛ schema جدید جایگزین رشد این فایل شود |
| app/aria_manager.py | کنترل Aria2، دانلود فوری و حلقهٔ زمان‌بندی؛ Adapter از orchestration جدا شود |
| app/scraper.py | ZarfilmBrowser با DrissionPage؛ منطق صف بیرون Adapter باشد |
| app/llm_agent.py | provider/model، failover و انتخاب فیلم/کیفیت؛ اختیاری و با fallback غیرLLM |
| app/static/index.html | پنل وب موجود؛ کاندید الگو/استفادهٔ مجدد پس از تعیین API |
| data/watchlist.csv | دادهٔ نمونهٔ همراه پروژه؛ خودکار به کتابخانهٔ جدید وارد نشود |
| run.sh | راه‌اندازی قدیمی؛ پیش از اجرا بررسی شود |
| requirements.txt | وابستگی‌های فعلی؛ با محیط و نسخه‌های جدید بررسی شوند |

README دانلودر بازهٔ ۲ تا ۷ و حداکثر دو دانلود هم‌زمان را توصیف می‌کند؛ این‌ها پیش‌فرض‌های قدیمی‌اند، نه الزام ثابت معماری جدید. قابل‌تنظیم‌بودن و رفتار واقعی کد باید آزمایش شود.

## بررسی‌های لازم پیش از انتقال
نشت secret در state/log، timeoutها، thread safety مرورگر، صف فوری در برابر زمان‌بندی، هم‌زمانی SQLite، نحوهٔ شروع daemon، پروفایل پایدار و بازیابی GIDها بررسی شوند. رفتارهای تبلیغ‌شدهٔ README را بدون تست، قابلیت تأییدشده تلقی نکنید.

اصل کار: کد قدیمی مرجع رفتار و منبع استفادهٔ مجدد است؛ وابستگی مستقیم هستهٔ جدید به کل برنامهٔ قدیمی ایجاد نکنید.
